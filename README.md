# OrderHub

Консольное приложение «Учёт заказов интернет-магазина» — итоговый проект по темам КТ31–КТ39
(«Коллекции, LINQ, перечислители и итераторы в C#»).

## Сборка и запуск

```
dotnet run --project src/OrderHub
```
